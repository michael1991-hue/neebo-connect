# Nivvi support FAQ — 20 September 2026

## How do I share with family?

Each person uses their own email. Phone next to the band: Family sharing → Create family code → send the 6 letters. Others type that code and choose Me, Partner, Mum, Dad, Nan or Carer. Whoever has the band taps I’m with [name]. Family also see the band battery. Same code when someone else takes over.

## Wi‑Fi PIN or family code?

4-digit PIN = same house Wi‑Fi. 6-letter code = another house or 4G via family.nivvi.app.

## Which devices work?

Bluetooth 180D heart-rate straps (Polar H10, Coospo, Magene, generic). Some 1822 pulse oximeters. Original Neebo. Not Apple Watch, Fitbit Air or Owlet in this build.

## Why connected but waiting?

Bluetooth is up; no heart-rate packet yet. Band on, charged, not in another app.

## Where is history for another day?

History tab: date at the top, or the arrows. The chart opens on the full calendar day. Charts and the list follow that date. 30 days on the iPhone.

## Will alarms always sound?

No. Open-app siren can ignore Silent. Lock screen can stay quiet in Silent, Focus or Sleep. Not a medical monitor.
