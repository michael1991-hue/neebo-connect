Information and support for the current Nivvi iPhone family-sharing test.

Testing is in progress. This is not a public App Store launch. Remote push alarms are unavailable in the current AltStore setup.

Understand what is shared

When enabled, family sharing sends the latest readings and status to the test server. Invited family accounts can view updates while the Family screen is open.

Read the family-sharing privacy notice →

Get help

Contact hello.nivvi@outlook.com. Please describe the issue without including account passwords, API keys or unnecessary personal information.

What this setup can and cannot do

The nearby iPhone receives wearable readings and uploads when the app and connection permit. The host PC must stay awake and online. The viewing phone needs internet access; old or missing readings are marked unavailable.

Background execution, connection losses and sensor behaviour still need testing. Do not rely on this family view for continuous observation or guaranteed alerts. It does not establish sensor accuracy or medical readiness.
