iPhone · family test

Peace of mind, every heartbeat.

Nivvi shows live heart rate from a compatible Bluetooth wearable on iPhone. Share downstairs on the same Wi‑Fi, or send a 6-letter family code so someone else can check in from another house or 4G.

Get TestFlight access

TestFlightiPhone onlyNot a medical device

Testing is in progress. This is not an App Store launch and not a medical monitor. Do not rely on it as the only way you look after someone.

How to get the app

  1. iPhone only for now. Android is not available.
  2. Install TestFlight from the App Store.
  3. Open this link on the iPhone: testflight.apple.com/join/32jtKDEM
  4. Tap Accept, then Install.
  5. Already installed? Open TestFlight → Nivvi → Update.

Use it in the house

Keep Nivvi open on the phone with the baby, connected to the wearable.

  1. That phone: Settings → Second iPhone on this Wi‑Fi → Share from this iPhone. Note the 4-digit PIN.
  2. Downstairs phone: same Wi‑Fi, type that PIN, turn on Follow the phone with the baby.
  3. Allow Local Network if iOS asks.

Family sharing (another house / 4G)

Uses the London server at family.nivvi.app. Each adult has their own email. Password at least 12 characters.

  1. Phone with the baby: Settings → Family sharing → Create family code → send the 6 letters.
  2. Family: own login, type the same code, choose Mum / Dad / Nan / Carer.
  3. Whoever has the band taps I’m with [child] — start monitoring.

Same code when someone else takes over. Do not tap Stop sharing with everyone unless you mean it.

What it can and cannot do

The nearby iPhone reads the wearable over Bluetooth. Family sharing works on Wi‑Fi or 4G. Alarms can miss if a phone is locked, on Silent, or offline. Nivvi is not clinically validated and is not a substitute for looking after the person.
