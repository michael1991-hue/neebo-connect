iPhone · family test

Calm readings on the phone nearby.

Nivvi shows live heart rate from a compatible Bluetooth wearable. Same-house Wi‑Fi share for a second iPhone. Optional family accounts when the home PC is on.

TestFlightiPhone onlyNot a medical device

Testing is in progress. This is not an App Store launch and not a medical monitor. Do not rely on it as the only way you look after someone.

How to get the app

  1. iPhone only for now. Android is not available.
  2. Email hello.nivvi@outlook.com with the Apple ID email you use on that iPhone.
  3. Install TestFlight from the App Store, accept the Nivvi invite, then install Nivvi.
  4. Already invited? Open TestFlight → Nivvi → Update.

Use it in the house

Keep Nivvi open on the nursery iPhone, connected to the wearable.

  1. Nursery phone: Settings → Family sharing → Share from this iPhone. Note the 4-digit code.
  2. Downstairs phone: same Wi‑Fi, type that code, turn on Follow the nursery iPhone.
  3. Allow Local Network if iOS asks. Keep Nivvi open on the nursery phone.

This path does not need the PC.

Away from home

Family accounts use family.nivvi.app on the home PC. The PC must stay awake with Docker and the tunnel running. Each adult uses their own email and a password of at least 12 characters. A code is emailed to verify the account.

Remote push sounds are not on yet. Live view needs the app and the PC online.

What it can and cannot do

The nearby iPhone reads the wearable over Bluetooth. A second iPhone on the same Wi‑Fi can follow that live view. Family accounts can show the latest snapshot when the PC is on. Background, Bluetooth range, charging and silent-mode behaviour are still being tested.

Nivvi is not clinically validated. It is not a substitute for looking after the person or for medical advice.

Get help

Contact hello.nivvi@outlook.com. Describe the issue. Do not send passwords, API keys or children’s photographs.
