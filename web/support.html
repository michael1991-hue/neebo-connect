FAQ

Short answers for the current TestFlight build. Not an emergency service.

How do I share with family?

Each adult creates their own Nivvi login. On the phone with the baby: Family sharing → Create family code → send the 6 letters. Others type that same code and choose Mum, Dad, Nan or Carer. Whoever has the band taps I’m with [child] — start monitoring. Do not send a new code when someone else takes over.

Wi‑Fi PIN or family code?

4-digit PIN = same house, same Wi‑Fi, downstairs. 6-letter family code = another house or 4G, via London. Mix Wi‑Fi and 4G is fine for family sharing.

Which devices work?

Bluetooth Heart Rate Service 180D straps (Polar H10, Coospo, Magene, generic Amazon HRM) and some pulse oximeters (1822). Original Neebo bands may still work. Apple Watch, Fitbit Air, Owlet and similar app-locked devices usually will not.

Why connected but waiting?

The phone has Bluetooth, but no heart-rate packet yet. Band on the skin, charged, not open in another app.

Where is yesterday’s history?

Open History. Use the date, or the arrows, to change day. Charts follow that date. About one card every 30 seconds, kept 30 days on that iPhone.

Will the alarm always sound?

No. Siren in the open app can ignore Silent. Lock-screen banners can stay quiet in Silent, Focus or Sleep. Not a medical monitor.

Password failed (422)?

Use at least 12 characters. Update TestFlight to the latest build.
